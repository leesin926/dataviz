## 一、项目概述

### 1.1 项目定位

构建一套企业级可视化数据分析及大屏展示平台，覆盖 PC 浏览器、PC 桌面端、小程序、手机 App、平板 App、大屏端六大终端形态，提供从数据接入、ETL 处理、数据建模、自助分析、仪表板编辑到大屏展示的全链路数据可视化能力。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 全终端覆盖 | 一套核心引擎，六端适配 |
| 全数据源接入 | 关系库、NoSQL、大数据、API、文件等 50+ 数据源 |
| 全链路数据治理 | ETL → 建模 → 指标 → 分析 → 展示 → 告警 |
| 企业级安全 | 多租户、RBAC+ABAC、行列级权限、数据脱敏、审计 |
| AI 增强 | NL2SQL、智能推荐、自动洞察、Copilot |
| 高性能 | 大屏秒开、百万数据渲染、高并发低延迟 |

### 4.2 大屏渲染引擎 (Screen Engine)

- **画布系统**：绝对定位 + 网格吸附 + 图层管理
- **渲染管线**：JSON Schema → 组件树 → 虚拟 DOM → Canvas/WebGL → 像素输出
- **适配策略**：整体缩放、固定宽度、自适应布局三种模式
- **性能策略**：
  - 组件懒加载（IntersectionObserver）
  - 数据增量更新（WebSocket diff）
  - GPU 加速（transform: translateZ(0)）
  - 离屏预渲染
  - 帧率控制（非活跃组件降低刷新频率）

### 4.3 ETL 编排引擎 (ETL Designer)

- **DAG 可视化**：基于 AntV X6 的节点编辑器
- **执行引擎**：
  - 轻量模式：后端线程池执行
  - 生产模式：Spark / Flink 分布式执行
- **算子运行时**：
  - 内置算子（50+）：Java 实现
  - 脚本算子：Groovy / Python / JS 沙箱执行
  - SQL 算子：直接下发到数据源执行
- **增量计算**：基于 CDC 的增量同步

  │ MySQL 主从  │    │ Redis 集群  │    │ Kafka 集群  │
