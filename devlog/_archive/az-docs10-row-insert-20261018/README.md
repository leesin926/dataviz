# AZ 轮 docs/10 表格行插入器（2026-10-18，归档不删）

AZ 轮往 `docs/10-移动端大屏重构进度表.md` 的「变更记录」表里插 **AZ0~AZ3** 一行。
直接用编辑工具追加失败过一次（我从被截断的 shell 渲染里重建行尾 ⇒ `0 occurrences`），
所以改成两段式：

- `az-changelog-row.md` —— 要插入的那一行原文（4,592 字符）。
- `az-insert-row.cjs` —— 按**唯一子串锚点**（`阶段 AY5：10 条 500 按证据拆成两层`）定位行，
  并守卫"锚点行必须以 `| 2026-10-18 |` 开头"，通过才在其后写入 `az-changelog-row.md` 的内容。

重跑会得到重复行 ⇒ 这个脚本是**一次性**的，只保留作"往长 markdown 表加行的正确形状"的证据。
详见 `devlog/EDIT_LOG.md` 阶段 AZ §七.3、报告 §19.34.8。
